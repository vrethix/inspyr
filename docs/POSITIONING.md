# inspyr.social — positioning v2

## Simple customer promise
**Know what to say next.**

## Category
**Self-learning growth engine**

## Elevator pitch
Inspyr watches what you build, figures out what is worth talking about, creates the right content for each channel, publishes it, and learns from what performs.

## What “learns” means
A previous action and its real outcome must change a future recommendation.

Example:
`robotics explainer → publish → 1.8× saves + 42% follow conversion → strategy signal updates → future ranking changes`

Analytics tells the user what happened.
Inspyr changes what it does next.

## Core loop
**Watch → Decide → Create → Publish → Measure → Learn → Repeat**

## Long-term thesis
Social/content is the first high-frequency environment for proving the loop.

Long-term category:
**Adaptive GTM**

Today: **What should we say next?**
Eventually: **What should this company do next to grow?**
